The first release replays captured PR reviews and coding-agent runs with selectable Python metrics. Run the examples from a fresh checkout with Python 3.12 or later. Replay requires no model credentials.

```sh
python -m unittest discover -s tests -v
python -m agent_eval --suite datasets/smoke/review.json --report artifacts/review.json
python -m agent_eval --suite datasets/smoke/coding.json --report artifacts/coding.json
python -m agent_eval --suite datasets/demo/coding-failure.json --report artifacts/coding-failure.json
```

Both smoke suites exit `0`. The deliberate coding failure exits `1`. Its report shows the regression check that failed and the unsupported completion claim.
